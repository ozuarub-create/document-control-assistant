# Week 22 Final Demonstration Recording Guide

## Recording Tool on MacBook

Use **QuickTime Player → File → New Screen Recording**.

## Recommended Length

5–7 minutes.

## Recording Sequence

1. Show the GitHub repository and Week 22 README.
2. Show `Dockerfile`, `docker-compose.yml`, and `.env.example`.
3. Start the application with `docker compose up --build` or Uvicorn.
4. Open `/production/readiness` and show the final-release checks.
5. Open `/auth/login-page` and log in.
6. Open `/docs` and authorize with the Bearer token.
7. Upload a sample PDF or DOCX document.
8. Show classification and extracted metadata.
9. Show review and compliance results.
10. Change the document workflow state.
11. Run a metadata or semantic search.
12. Open the relationship viewer.
13. Ask a multi-document question through `/conversation/ask` and show citations.
14. Open `/dashboard` and show analytics.
15. Finish with the architecture diagram and final presentation.

## Spoken Summary

“This final application combines all modules developed during the project. It supports secure users, complete document lifecycle management, Docker deployment, technical documentation, analytics, relationship mapping, and cited conversational document questions.”

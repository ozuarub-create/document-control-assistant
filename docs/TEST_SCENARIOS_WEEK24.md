# Week 24 Test Scenarios

1. Revised architectural drawing - detect prior revision and route for technical review.
2. Open RFI - route to responsible engineer for response.
3. Incomplete material submittal - return for missing revision/date metadata.
4. Revised specification - search related knowledge and summarize.
5. Meeting minutes - summary-only request demonstrating limited tool selection.
6. Inspection report - generate comments and recommend action.
7. Method statement - approval-oriented review flow.
8. Material submittal revision - detect previous approved revision.
9. New mechanical drawing - classification and metadata-only task.
10. Closed RFI - summary task without unnecessary next-action tools.

The scenarios are intentionally varied so the execution log demonstrates that the agent chooses different tool sequences rather than running all tools every time.

# 15-Minute Demo Guide

1. Explain the simulated project dataset (2 min)
2. Show the investigation request and generated plan (2 min)
3. Show multi-step tool execution and relationships (3 min)
4. Show conflict detection and evidence citations (2 min)
5. Show Fact / Inference / Recommendation separation (2 min)
6. Show executive report output (2 min)
7. Show evaluation dataset, tests and architecture diagram (2 min)
